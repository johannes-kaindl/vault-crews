# Vault Crews — documentation

Organised after [Diátaxis](https://diataxis.fr/): learning something and fixing something are different needs, so they live on different pages. Only the kinds that have content are listed here.

**New here?** → [Getting started](getting-started.md) — from the install to your first crew run and its undo.

**Something not working?** → [Troubleshooting](troubleshooting.md) — the exact message you see, what it means, what to do, and where to get help.

| | |
|---|---|
| **[Getting started](getting-started.md)** | Learning-oriented. Connect a local model, install the example crews, run one and undo it. |
| **[Troubleshooting](troubleshooting.md)** | Task-oriented. "Run refused", "Waiting for output…", "found 0 matching notes", "No crews found". |

The [README](https://github.com/johannes-kaindl/vault-crews/blob/main/README.md) covers what the plugin does, how to install it, every setting, the safety model and how to write your own crews.

`SMOKE.md` holds maintainer material (the GUI smoke checklist) and is not user documentation.
